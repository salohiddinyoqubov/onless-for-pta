# Security policy

## Private disclosure

Please do not open a public GitHub issue, discussion, or pull request for a suspected security vulnerability.

Send a private report to `s.yoqubov@onless.uz` with:

- a concise description of the issue and its potential impact;
- the affected file, component, or endpoint;
- reproducible steps or a minimal proof of concept; and
- any suggested mitigation, if available.

Do not include real user data, production credentials, destructive payloads, or data obtained by exceeding the authorization granted to you. Receipt and remediation timelines depend on severity and the information available; no fixed response or resolution time is promised.

## Scope

This repository is a public, non-production technical showcase. Reports about the code and local container configuration in this repository are in scope. The private Onless product, third-party services, production infrastructure, and social-engineering attempts are out of scope unless the owner has separately provided written authorization.

The public issue tracker, if enabled, is suitable only for non-sensitive correctness and documentation reports.
